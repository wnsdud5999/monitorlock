# monitorlock

개인 맥에서 음악 재생 중 화면이 자동으로 잠기는 상황을 줄이기 위한 아주 단순한 단일 페이지입니다.

## 실행

브라우저에서 `index.html`을 직접 열면 됩니다.

또는:

```bash
python3 -m http.server 8080
```

그 뒤 `http://localhost:8080` 접속.

## 동작 방식

- 1x1 검은 캔버스 스트림을 `video`로 무한 재생 (무음)
- 브라우저가 지원하면 `Screen Wake Lock API`도 같이 요청

## 주의

- 브라우저/OS 정책에 따라 100% 보장되지는 않습니다.
- 개인 장비/개인 정책에서만 사용하세요.
